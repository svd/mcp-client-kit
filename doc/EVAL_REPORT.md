# Cross-Server Synthesis

_18 servers evaluated: astro-docs, aws-knowledge, cloudflare-docs, codegraph, context7, deepwiki, everything, exa, fetch, filesystem, git, github, huggingface, memory, openzeppelin-solidity, sequential-thinking, sqlite, time._

## Overall verdict

All 18 servers pass, with no manual wrapper fixes required and only one non-green check across the suite (github `signatures`, skipped for three tools that hit live auth/quota errors). The skill's defining strength remains restraint: it repeatedly declined to invent structure it could not observe — sqlite `read_query`, github's method-multiplexed readers, filesystem `directory_tree`'s recursive JSON, aws-knowledge's dynamic product catalogs, and memory's empty-store inner list shapes were all left honestly `Any`/`dict` rather than force-typed.

## Mode coverage gaps

Nine servers landed Mode A only. For most (cloudflare-docs, codegraph, deepwiki, exa, fetch, git, huggingface, openzeppelin-solidity) that is correct — payloads are prose or fenced source, and `json.loads()` was actually attempted and failed. Three gaps are real:

- **everything**: most tools typed `str` only because probes read the text envelope; `image`/`resource`/`resource_link` content blocks are invisible. Probing the full content-block union should lift several to B/C.
- **github**: Mode D is unreachable by construction — discriminator codegen coerces variant keys with `int()`, so a string discriminator like `method` cannot be emitted. A codegen limit, not a probing gap.
- **context7 `resolve-library-id`**: record-shaped data delivered as a delimited plaintext listing; with no parser, `Any` was the only honest option.

Mode D remains unhit across all 18 servers. aws-knowledge shows the workaround that does work: multi-probe plus deep-merge into one `total=False` union when the discriminator is list-valued.

## Known issues

1. **Mutation triage leans on semantics.** Where `readOnlyHint` is absent (fetch, sqlite `append_insight`, astro-docs) safety rests entirely on description reading. No structural backstop.
2. **Multi-probing costs roundtrip.** `verify.py` rejects list-valued `probed_args`, penalizing the servers probed most thoroughly.
3. **Stale shapes survive merge.** huggingface carried dead entries from a prior run; codegen would emit wrappers for tools the server no longer exposes.
4. **Live errors read as null shapes.** github `get_team_members` conflated a token-scope failure with a genuine empty response.

## Next steps

1. **Index `probed_args[0]` for roundtrip replay** — cheapest fix, restores coverage on every multi-probed server.
2. **Make discriminator codegen key-type-agnostic** — unlocks Mode D, currently 0/18.
3. **Probe the full content-block union**, not just text — the single change most likely to convert Mode A servers into B/C.
