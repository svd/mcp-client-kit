## Cross-server synthesis

# Cross-server synthesis

## Overall verdict

Across 27 servers the skill produced 24 passes and 3 partials (firecrawl, github, notion);
every module parsed, regenerated byte-identically, and scrubbed PII. Its strongest recurring
behaviour is restraint — on the 14 Mode-A-only servers `-> Any` was the honest answer, and no
run fabricated a `TypedDict` over prose.

## Mode coverage gaps

Most Mode-A-only servers are prose-by-design, and richer probing would not change the result:
docs search (cloudflare-docs, deepwiki, huggingface, context7, exa), the four openzeppelin
contract generators, CLI stdout (git), markdown reports (playwright, codegraph), single-fetch
(fetch). Exa is the one drift case — the manifest anticipated nested JSON, but both tools now
return markdown, so Mode A reflects the server changing, not weak probing.

The gaps that are real are environmental:

- **firecrawl** — `FIRECRAWL_API_KEY` unset; all 3 tools returned the same 189-byte auth error,
  so shape inference was never exercised. The only run where Mode A means "unmeasured", and a
  side diagnostic confirmed the endpoint answers anonymously with a shapeable payload.
- **memory, linear, notion, semgrep** — empty or entitlement-limited stores. The unwrap path was
  found but element models stayed unobservable (~20 Linear tools, memory's
  `entities`/`relations`, `get-comments`, `semgrep_findings`).
- **github** — 3 tools inconclusive on live 403/404s, correctly left untyped.

**Mode D was hit zero times in 27 runs.** The cause is consistent across the corpus: real
polymorphism lives in the *response* key, not an argument — Notion's `page | database`,
StackOverflow's `Data.Type`, GitHub's `method` on `issue_read`/`pull_request_read` — and
overload emission cannot key on those. Argument-level candidates were plentiful (46 on Linear,
10 on playwright) but nearly all were identity or construction inputs, disqualified correctly.

## Known issues

1. Fresh-process statelessness distorts probes: playwright's tracing preconditions, memory's
   always-empty graph, and the same effect behind sqlite's unpinned-`uvx` breakage.
2. Credential and plan walls dominate the partials. In every case the skill set
   `_probe_status: "inconclusive"` rather than typing an error envelope — which is what
   downgrades `signatures` to a skip (`eval_harness/verify.py:112-123`), so the partials read
   as honest abstention, not failure.
3. Server-side schema quirks cost typing on the input side too: openzeppelin-stellar declares
   enums as `anyOf`-of-`const`, so `access`/`policy`/`limitations` widen to `Any | None`
   instead of `Literal`.
4. The corpus spans three engine versions (doc/EVAL_REPORT.md:5), so aggregate counts mix
   releases and are not comparable run to run.
