# Cross-server synthesis — generate-mcp-wrappers

Engine 0.9.0.dev1 · skill `v0.0.4-156-gfd9eda8` · 27 servers

## Overall verdict

The skill performed well across all 27 servers: 23 pass and 4 partial (`github`, `linear`,
`notion`, `playwright`), with no server producing a broken or fabricated artifact. The
consistent strength is restraint — on prose-returning servers it left `-> Any` and empty
`unwrap` instead of inventing TypedDicts, and every unobserved shape was marked
`_probe_status: inconclusive` rather than guessed.

## Mode coverage gaps

Thirteen servers hit Mode A only, but for most of them that is the correct answer, not a
gap: `cloudflare-docs`, `codegraph`, `context7`, `deepwiki`, `exa`, `fetch`, `git`,
`huggingface` and the four OpenZeppelin generators all return Markdown or fenced source
text, verified `NOT_JSON` by the JSON-in-string guard. Richer probing cannot yield B/C
there — there is no record behind the prose.

The genuine gaps are environmental:

- **Empty accounts.** `linear` (a dozen list tools returned `[]`, ten getters errored) and
  `notion` (`get-comments`) had nothing to observe. `semgrep` is worse: the hosted endpoint
  is tombstoned, so four tools returned a deprecation notice and only `semgrep_whoami`
  shaped.
- **Ids mintable only by mutating tools.** Five `firecrawl` tools and two `notion` tools
  were dropped unprobed because their required id comes from a write call the eval never makes.
- **Credential scope.** `github` left `get_team_members` (null) and
  `list_repository_collaborators` (403 on PAT scope) inconclusive.
- **`playwright`** is the one arguable case: five tools returned only errors
  (`No open pages available.`), so its partial reflects missing browser state, not prose.

## Known issues

Recurring across servers: schema lies about required args (`linear.list_comments`,
`semgrep_findings`'s `repos: default []`); discriminator candidates that probe identical
and stay inconclusive rather than disproven (`firecrawl`, all four OpenZeppelin servers,
`playwright`); and `anyOf`-of-`const` enums rendering as `Any | None` instead of
`Literal[...]` (`openzeppelin-solidity`).

## Next steps

1. **Seed the empty workspaces.** Add `seed` commands for `linear` and `notion` (and a
   pre-minted crawl id for `firecrawl`) so the ten-plus unobservable tools produce records.

   deprecation notice points at; the current run measures an upstream tombstone.

   types the input side on every generator-style server.
