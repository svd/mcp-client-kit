# Cross-server synthesis

## Overall verdict

Across 27 servers — all now on one engine, `0.9.0.dev1` in every `result.json` — the skill
produced 23 passes and 4 partials (github, linear, notion, playwright). Every module parsed,
regenerated byte-identically, and cleared the PII scrub; the recurring strength is restraint,
with no run fabricating a `TypedDict` over prose.

## Mode coverage gaps

Thirteen servers stayed Mode A only: cloudflare-docs, codegraph, context7, deepwiki, exa,
fetch, git, huggingface, playwright, and the four openzeppelin generators. For twelve of them
that is the measurement, not a gap — every payload tested `NOT_JSON` on a genuine success, so
`-> Any` is the honest signature and richer probing would change nothing. Playwright is the
real gap: five of its 17 probed tools returned only precondition errors (`Tracing is not
started`, `No open pages available`) because each probe spawns a fresh process, so their
shapes were never observable.

Mode D was reached four times this run — `get_regional_availability` (aws-knowledge),
`map.sitemap` (firecrawl), `notion-search.query_type`, and `semgrep_findings.issue_type` —
so argument-keyed overloads are demonstrably reachable. Where they were not, the reason was
consistent: the polymorphism lives in the response (stackoverflow's `Data.Type`), or the
switching argument is on the engine denylist (`query` on six servers; `method` on GitHub's
`pull_request_read`/`issue_read`, whose 14 variants were probed but could not be typed).

## Known issues

1. **Stateless probing.** Playwright's five inconclusive tools; contrast sequential-thinking,
   which got a shaped `ThoughtStatus` only by chaining three calls into one process, and
   memory, which needed harness seeding to see past `{"entities": [], "relations": []}`.
2. **Unmintable ids.** Firecrawl left 5 readers unprobed, notion 2, linear 6 — all need ids
   only a skipped mutating tool produces. Every case was marked inconclusive, which is what
   downgrades `signatures` to a skip (`eval_harness/verify.py:112-122`).
3. **Server schema quirks cost input typing.** `anyOf`-of-`const` instead of `enum` widens
   `access`/`policy` to `Any` (openzeppelin-solidity, -stellar); `number` where `int` is meant
