# Cross-Server Synthesis

## Overall Verdict

The skill passed all 13 servers it reached, with no manual wrapper fixes needed. Its strongest trait was restraint: it repeatedly declined to invent structure rather than guess — sqlite `read_query` (two sample queries merged into an unrelated `email`/`price` column union, correctly left `-> Any`), github's method-multiplexed `issue_read`/`pull_request_read`, `get-env`, `get_file_info`. `radar` produced no signal — an expired OAuth grant blocked codegen entirely, a credential issue, not a skill defect.

## Mode Coverage Gaps

Mode A dominance is mostly honest: codegraph, deepwiki, fetch, git, and huggingface genuinely return prose, confirmed by failed `json.loads()` on every probe. Three gaps are real:

- **everything**: 10 of 11 probed tools typed `str` only because the probe reads the text envelope; `image`/`resource`/`resource_link` content blocks are invisible to it. Probing the full content-block union should lift several to Mode B/C.
- **github**: Mode D is structurally unreachable — mcpgen's discriminator codegen keys variants with `int()` (`codegen.py:281/301/312`), so a string discriminator like `method` crashes. This is a codegen limit, not a probing gap.
- **context7 `resolve-library-id`**: semantically record-shaped output delivered as a delimited plaintext listing; with no parser, `-> Any` was the only honest choice.

## Known Issues

1. **Mutation heuristic is unreliable both ways.** It under-flags domain verbs (git `commit`/`checkout`, sqlite `append_insight`) skipped only on semantic judgment, and can false-positive on prose matches. No structural backstop exists beyond the live-call guard.
2. **Multi-probing forfeits roundtrip.** `verify.py` rejects list-valued `probed_args`, so time, sqlite, and everything lost roundtrip coverage as a direct penalty for probing more thoroughly.
3. **Stale shapes survive merge.** `mcpgen merge` carried a dead `paper_search` entry into huggingface from a prior run; codegen would emit wrappers for tools the server no longer exposes if unnoticed.
4. **`get_team_members` (github)**: PAT-scope `NoneType` response caused `probe_inconclusive`, conflating auth failure with a genuine null shape.

## Next Steps

1. **Index `probed_args[0]`** for live-call replay — restores roundtrip coverage on 3 servers, cheapest fix.
2. **Replace the mutation-keyword list** with the tool's `readOnlyHint` annotation, falling back to name/description semantics.
3. **Make discriminator codegen key-type-agnostic**, unlocking Mode D for string-discriminated tools github already found and correctly declined to guess at.
